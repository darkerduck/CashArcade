# CashArcade

一款零依賴、純前端的復古貪吃蛇遊戲。

🎮 **開始遊玩：** <https://darkerduck.github.io/CashArcade/>

## 操作方式

- 使用方向鍵或 `WASD` 移動。
- 按 `Space` 暫停或繼續。
- 按 `R` 立即重新開始。
- 手機和平板可以使用畫面下方的方向鍵，或直接在遊戲區滑動。

吃到光點會獲得 10 分；每吃到五個光點，遊戲速度就會提高。最高分只會儲存在目前瀏覽器的 `localStorage`。

## 技術

CashArcade 使用 HTML、CSS、JavaScript 與 Canvas 製作，不包含框架、後端服務、追蹤程式或第三方依賴。
