## 瀏覽器

- Windows Chromium 內嵌瀏覽器確認首頁載入 1672 × 941 無文字封面，第十五張遊戲卡可進入第一關。
- 實際開局以鍵盤使用氮氣，速度達到 209 km/h，氮氣由 42% 減至 15%。煞車後降至 98 km/h。暫停後倒數保持 69.3 秒，配樂回到待命。未觀察到 console error 或 warning。
