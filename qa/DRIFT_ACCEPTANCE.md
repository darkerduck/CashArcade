# Drift 升級雲端驗收

此交付尚未 commit/push/發布。基準 main：fa0e9fe（包含 Reactor 修復）。Mac 未啟動瀏覽器、未跑遊戲／物理回放；以下全部交給 assistant 雲端執行。

## 執行

1. 解壓完整 checkout（不含 .git）至私有測試目錄。先跑 `sh qa/run-drift-node.sh`。Node 22+，無 npm 安裝。
2. `python3 -m http.server 4173 --bind 127.0.0.1`，由 assistant 雲端 Chromium 開 `/drift/`。
3. 若雲端已有 Playwright，可跑 `node qa/drift-browser.mjs http://127.0.0.1:4173/drift/`。此腳本採公開引擎正常輸入回放驗證結果 UI，也包含真實 DOM 鍵盤與 CDP 多指取消；不等同 90 秒人類鍵盤駕駛驗收。預設截圖存 /tmp/drift-qa，仅供內部 QA，不需上傳 Library。
4. Node/浏览器失敗需回傳完整測試名稱、錯誤與重現操作。若有修正，將修正檔或 patch 回傳此 Mac 執行緒，重新匯出交付後再驗。不得以預期通過代替實測。

## 驗收規則

- 三條短賽道、自動油門、左右轉向、Space/Shift 甩尾蓄能／釋放加速、雙拇指及原創三首 8-bit 音樂仍可用；沒有付款、帳號或新外部依賴。
- 全車包圍圓半徑 18.5px 在道路半寬 57px 內，中心最多偏離 38.5px。高速／boost 兩邊護欄、所有轉角不能穿牆；碰撞帶滑動反應，轉向可離牆，無卡死。外部位置污染會防禦性修正，但正常駕駛不使用傳送。
- 正向法線撞擊 >=35px/s 才扣 5–24 耐久；0.9 秒冷卻。連續擦牆不能瞬間爆炸，反覆高速新撞擊可毀車。撞擊打斷 boost/連段，耐久 0 顯示爆炸並停止賽事。重試完整修復。
- 至少兩台有不同顏色與名稱的 AI，正常油門上限 190/198px/s（玩家 215，boost 345）。所有車共用道路碰撞、耐久、八個依序 checkpoint、合法圈數與進度。AI 沒有追趕傳送或依玩家位置調速；不新增車對車碰撞，車輛交會可重疊。
- 按完整有效圈數及本圈有效前進距离排名；逆行扣回進度，跨起點逆行／跳 gate／外部 relocation 使本圈失效。同距離以耐久高者領先，完全平手保守判玩家非第一。零合法圈不算勝利。
- 完整 90 秒第一名、車未毀、目前圈未失效才勝利解鎖下一賽道；第二／三名、爆炸或無效進度不能解鎖。勝利按鈕進下一賽道預備畫面；重試按鈕可重玩原賽道。第三道勝利可重玩。
- 初次仅第一道开放；第一／二道奪冠逐道解鎖。重新整理保留解鎖、選道、紀錄、音訊偏好，未完成賽事不恢復。舊版任意選道回到第一道，但舊分數／圈速保留。localStorage 拒絕時本頁照常解鎖與免費重玩。
- 暫停、失焦、分頁隱藏凍結玩家/AI/耐久/90秒時鐘並清除輸入；再次操作繼續。ready/勝負/爆炸畫面停止配樂。
- 桌面、390px 手機，暗／亮版、減少動態、橫直向與全螢幕檢查 HUD 六格、overlay、觸控按鈕與無橫向溢出。鍵盤操作音量與原生按鈕不誤轉向。pointercancel/lostpointercapture 要釋放兩指。
- 音效／音樂獨立靜音及音量，原生 AudioContext/AnalyserNode 實際非零音訊、暫停靜音；人工確認撞擊和爆炸音效及清楚對手可見性。Node 假音訊測試不能替代此項。
- 完整 `tests/*.test.mjs` 檢查其他遊戲及 Reactor 回歸；diff 僅 drift、其測試、相關文件與 qa。

## 風險與待確認

1. AI 的三道完整回放、普通玩家可贏性、第三道最急彎與貼牆轉向手感待雲端實測；對手速度選擇尚未調校。
2. 新進度合法性門檻與更小可用路寬可能讓旧 driver 測試需要調整；若失败，先確認物理／圈数正确，不降低防作弊門檻來掩飾。
3. 有更多道路投影查詢，需要確認手機 30fps 畫面／物理負荷，尤其全螢幕。
4. 目前爆炸為焦黑車體與固定爆炸光點，撞擊為短暫閃光；視覺／音訊仍需真實瀏覽器確認。
5. 雲端 QA 通過再通知此執行緒，會重新確認 origin/main，保留並整合遠端新變更後，完成已授權 commit/push/Pages。此包不含任何已發布聲明。


## 第二版修正（待雲端重驗）

第一輪雲端：Drift 41 項中 39 通過，第三道有效圈與90秒第一名回放失敗。靜態幾何檢查顯示該道最小曲率半徑约21px，小於38.5px的車心走廊，最近道路投影在彎道內側可能跳動，原「每步投影弧長<=位移三倍」並不成立。第二版取消此不適用的速度推斷，改以車輛上一／目前實際位置掃過有方向且限道路寬度的8個checkpoint閘門及起點判定；保留<=2px道路掃掠、外部位置跳轉失效、投影大跳限制、逆行失效、依序閘門、合法距離與完整圈要求。原失敗斷言保持不變，新增投影跳動不能替代物理閘門與閘門方向／範圍測試。此修正尚未在Mac跑物理測試，需雲端驗證診斷及結果。


雲端追加證據：第三道玩家 t=3.844s 實位移1.174px／道路投影4.078px；VIOLET t=4.533s 1.038／3.177px；AMBER t=4.578s 1.082／3.335px，皆約progress .342→.344且無碰撞。已新增三組數值的回歸案例。第一轮全套578項576通過，僅前述第三道兩項失敗。

另外修正同幀 `event('explosion')`→`update(destroyed)` 切斷尾音：終局關掉配樂排程與合成器但保留有排定結束時間的SFX，音效自行onended釋放；一般暫停、重新選道與pagehide仍完整停止。新增爆炸／完賽尾音順序及明確pause中斷測試；需雲端再做真正AudioContext輸出驗證。
