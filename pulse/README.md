# 雙軌節奏 / Pulse Switch

原生 Canvas 2D / Web Audio 雙軌節奏遊戲；所有內容免費，無付款、登入、追蹤、第三方執行期資源。

## 原創樂曲與譜面

| 樂曲 | BPM | 小節 | 長度 | 巡航 / 脈衝音符 |
| --- | --- | --- | --- | --- |
| 餘光列車 / Afterglow Express | 110 | 32 | 69.82 秒 | 103 / 114 |
| 玻璃海岸 / Glass Coast | 126 | 36 | 68.57 秒 | 117 / 129 |
| 離子午夜 / Ion Midnight | 144 | 40 | 66.67 秒 | 134 / 154 |

四組手寫旋律、各曲和弦進行與節奏網格位於 `tracks.js`。每首有 intro、pulse、break、outro 編曲。方波主旋律、三角低音、琶音、底鼓與噪音鼓由共用 `../music.js` 的 `CashArcadeMusic.synth()` 合成。沒有取樣外部錄音。三首各有巡航、脈衝譜面；生成不使用隨機數，從與音樂相同的十六分格點產生，保留同軌長音後的放開／再按間距。

## 操作與計分

- 左軌 F / ←，右軌 J / →。手機使用下方雙軌按鈕，支援多指同按。
- 短音按下、長音起點按下與尾端放開各為獨立判定。長音未命中起點，起點與尾端皆算失誤。
- 金色雙軌閘門需同時按兩軌；各自判定，不要求額外按鍵。
- 巡航 PERFECT / GREAT / GOOD：±65 / 125 / 185 ms。
- 脈衝 PERFECT / GREAT / GOOD：±45 / 90 / 145 ms。
- PERFECT / GREAT / GOOD / MISS 權重 1 / .75 / .4 / 0。分數為所有判定權重總和 ÷ 譜面總判定數 × 1,000,000；最高固定一百萬分。顯示的準確率為已判定部分，歌曲完成時與總分一致。
- 空拍打斷連段但不消耗音符。長音提前放開、拖過尾端判定窗口，皆記尾端失誤。多指或替代按鍵重疊不重複計分。
- S / A / B / C / D 門檻為 98% / 92% / 82% / 70% / 以下。全連要求零 MISS 且零空拍。
- P / Esc 暫停，R 回準備畫面。切換曲目／難度開始新譜面。瀏覽器離焦、離頁、音訊暫停會自動暫停。

## 同步、暫停與校正

`audio.js` 管理唯一歌曲 epoch，25 ms lookahead 排程十六分音符到 Web Audio 的絕對秒數。畫面和輸入讀取同一音訊時鐘；支援時使用 `getOutputTimestamp()` 將音訊時鐘對應實際輸出與輸入事件時間，否則使用 baseLatency / outputLatency 估計。音樂靜音、音量改變、低幀率不重設 epoch。長時間排程卡頓會跳過過期聲音而非突然補播。

開始前四拍預備。暫停停止已排程音樂／音效，凍結譜面秒數；恢復前兩拍預備並以同一歌曲位置續排，不重新播曲。長音可在預備期按回原軌；正式恢復後 220 ms 內未按回會記失誤。重新開始會清空輸入與計分。音訊不可用時提供視覺拍點的靜音遊玩，以單調時鐘維持速度；不宣稱無 Web Audio 時具有聲畫同步。

跟拍校正播放原創 100 BPM 節拍，先聽三拍，再點十二次。去掉上下 20% 偏差後取平均；樣本少於八次或分散超過 55 ms 時不覆寫原設定。正值補償晚按，負值補償早按；範圍 ±250 ms。校正節拍會暫時發聲，完成／取消即停止。延遲變更會回到準備畫面，以免一張進行中的譜面使用兩套判定時間。藍牙裝置的延遲可能超過可校正範圍，建議喇叭／有線耳機。

`storage.js` 驗證 `casharcade-pulse-v1`：每曲與每難度紀錄分開，保存最高分、最高準確率、最大連段、完成次數。音樂與音效的開關／音量、校正、減少動態效果皆獨立保存；存取失敗只警告，不阻擋免費遊玩。

## 維護與驗證

- `engine.js`：純計分、判定、長音、閘門、暫停恢復。
- `controller.js`：事件時間校正、鍵盤／多指來源去重。
- `renderer.js`：純 Canvas 2D 雙軌透視、拍點、蓄能與命中提示。
- `game.js`：DOM、曲目／難度、生命週期、紀錄、校正。
- `window.PulseSwitch.snapshot()`：唯讀、脫離內部物件的診斷快照；包含譜面、判定、音訊 epoch、排程步、設定與校正進度。沒有任意注入狀態或無敵入口。

執行 `node --test tests/pulse-*.mjs`。測試涵蓋六張譜面完整 PERFECT 回放、可演奏性與音樂格點、判定邊界、長音提前／拖尾／漏按、閘門、暫停接續、去重、靜音同步、排程卡頓、延遲公式、跟拍校正、存檔容錯、頁面鍵盤／觸控與整曲完成回放。瀏覽器需另驗證桌面與 390px、亮暗版、實際聲音、校正、音訊中斷與返回；Node 假環境測試不代表真實裝置音訊驗收。
